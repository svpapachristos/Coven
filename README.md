# witchygirl
a small top-down maybe-soon-to-be "game" prototype made in GameMaker.
Tile-based background, with a camera following a small witch walking around a field, limiting the player to a confined grass area. Now able to shoot little purple blasts! enemies soon!
This project was a "dipping the toes into the water" moment for me and taught me that self learning coding is not as hard as it seemed and is actually super fun.
